22/**
23 * @brief Solves the Momentum Equations using Dual-Time Stepping with a Fixed-Point RK4 Smoother.
24 *
25 * =================================================================================================
26 * GLOSSARY & THEORETICAL BASIS
27 * =================================================================================================
28 * 1. METHODOLOGY: Dual-Time Stepping (Pseudo-Time Integration)
29 * We aim to solve the implicit BDF equation: R_spatial(U) + dU/dt_physical = 0.
30 * We do this by introducing a fictitious "Pseudo-Time" (tau) and iterating to steady state:
31 * dU/d(tau) = - [ R_spatial(U) + BDF_Terms(U) ]
32 * When dU/d(tau) -> 0, the physical time step is satisfied.
33 * 2. ALGORITHM: Fixed-Point Iteration with Explicit Runge-Kutta
34 * This is technically a Fixed-Point iteration on the operator:
35 * U_new = U_old + pseudo_dt_scaling * dt_pseudo * Total_Residual(U_old)
36 * We use a 4-Stage Explicit RK scheme (Jameson-Schmidt-Turkel coeffs) to smooth errors.
37 * 3. STABILITY: Backtracking Line Search
38 * If a pseudo-time step causes the Residual or Solution Error to GROW (Divergence),
39 * the solver "Backtracks": it restores the previous solution, cuts the pseudo-time step
40 * scaling factor (pseudo_dt_scaling) in half, and retries the iteration.
41 * =================================================================================================
42 * VARIABLE MAPPING
43 * =================================================================================================
44 * -- Physics Variables (Legacy Names Kept) --
45 * ti : Physical Time Step Index.
46 * dt : Physical Time Step size (Delta t).
47 * st : Pseudo-Time Step size (Delta tau).
48 * alfa : Runge-Kutta stage coefficients {1/4, 1/3, 1/2, 1}.
49 * -- Convergence & Solver Control (Renamed) --
50 * pseudo_iter : Counter for the inner dual-time loop.
51 * pseudo_dt_scaling : Adaptive scalar for the pseudo-time step (formerly lambda).
52 * delta_sol_norm : The L_inf norm of the change in solution (dU).
53 * resid_norm : The L_inf norm of the Total Residual (RHS).
54 * =================================================================================================
55 *
56 * @param user Primary `UserCtx` input for the operation.
57 * @param ibm Parameter `ibm` passed to `MomentumSolver_DualTime_Picard_RK4()`.
58 * @param fsi Parameter `fsi` passed to `MomentumSolver_DualTime_Picard_RK4()`.
59 * @return PetscErrorCode 0 on success.
60 */
61PetscErrorCode MomentumSolver_DualTime_Picard_RK4(UserCtx *user, IBMNodes *ibm, FSInfo *fsi);
