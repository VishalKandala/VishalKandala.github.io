Detailed Description

The PETSc binary Vec envelope of PICurv's checkpoints and staged fields: its reader, writer and validator, shared by the conductor and the generators.

Not a command. core.py, ic.gen, profile.gen and spectra.gen import it from picurv_cli/, as they import periodic_spectral.py. The envelope is a class id and a scalar count, each a PetscInt of the writing build's width, then real64 values, all big-endian.
