Tests that setup refuses every flag whose feature is planned but not implemented.

Multi-block coupling, immersed boundaries, moving bodies, moving frames and the immersed-body flux corrections were all accepted before, and each ran a different problem without saying so. The conductor refuses the YAML switches; this covers the same flags arriving through a PETSc passthrough. Each flag is appended to an otherwise valid control file, so a later duplicate overrides the fixture's own value.
