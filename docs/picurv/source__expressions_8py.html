Detailed Description

The source expression language on the Python side: its functions and variables, validation, constant substitution, region lowering and NumPy evaluation.

The CLI checks every source with it before a run; generators/ic.gen evaluates one with it. The solver evaluates the same language in src/expression.c, and tests/test_expression_language.py holds the two to one conformance fixture.
