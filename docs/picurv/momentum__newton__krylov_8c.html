Adapts a PETSc trial vector to the existing momentum residual path.

A matrix-free SNES residual must be a deterministic function of the trial vector X alone: F(X) may not depend on any state left by a previous residual or MFFD evaluation, or finite-difference Jacobian actions become inconsistent. To honor that contract this callback fully derives the Cartesian velocity state (Ucat/lUcat) from X before the first boundary sweep – see the inline comment below for why ApplyBoundaryConditions()'s own internal reconstruction is not sufficient for the first outlet pass.

State invariants:

  • On entry, X is the only input that determines the result; user->Ucont, user->Ucat and their local ghosts are treated as scratch and are fully overwritten from X.
  • Supported handlers may overwrite flux totals and other diagnostics on every call, but those values must not affect a later call at the same X; the deterministic seed guarantees this.
  • No histories, pressure, viscosity, or controller state advance here.

Side effects: overwrites user->Ucont/lUcont, user->Ucat/lUcat, user->Rhs, the boundary Ubcs targets, and boundary flux/area diagnostics; writes F.

Replaces every non-independent residual row with an explicit equation.

Which rows are non-independent is decided by ClassifyMomentumRow(), shared with the residual path; only the action taken differs. Conditioned face-normal rows use F=X-Uconditioned, unconditioned legacy dummy/tangential rows use F=X, and periodic duplicates use Fdup=Xdup-Xrep. These equations prevent the zero Jacobian rows that EnforceRHSBoundaryConditions()'s zeroing would produce in a matrix-free Newton operator. Immersed and interface rows are rejected before this callback is installed. A TwoD-masked component needs no constraint: ComputeRHS() zeroes its spatial terms, so its row is the time derivative alone, which holds a velocity that is constant in time exactly, as the Picard solver's skipped row does.

Measure the residual at the iterate a failed SNES solve holds, for the failure policy in MomentumSolver_NewtonKrylov().

SNES judges the residual by absolute and relative tolerances that do not scale with the grid or the flow. Near a steady state the residual can reach the round-off floor of its own evaluation; the line search then cannot decrease it and SNES reports divergence for a state that is as converged as the discretization allows. The caller therefore judges the held iterate itself: by the dual-time solver's dimensionless test, |R|_inf <= mom_resid_atol * a0 |U|_inf / dt, and by whether its residual is finite and no larger than the residual the step started from.

Solves one physical momentum step with matrix-free Newton–Krylov.

The Jacobian operator is the finite-difference, matrix-free operator of the complete deterministic residual. With no mathematical preconditioner its matrix is also passed to PETSc's preconditioning slot and PCNONE is derived. The optional provisional frozen-momentum, point-block model approximates same-cell frozen coupling, owns a separate matrix, and derives a block-Jacobi PETSc backend. It does not relax the version-one physics or boundary-condition restrictions. The PETSc solver objects are built on the first call and kept for the run in UserCtx::momentumNewtonKrylov (MomentumSolver_NewtonKrylov_Destroy() releases them), with UserCtx::Rhs; a step that fails releases both, so the next call builds afresh. Rows removed by legacy boundary residual enforcement are made explicit: conditioned normal rows use X-Uconditioned, untouched dummy/tangential rows use X, and periodic duplicates use Xdup-Xrepresentative. Unsupported masked, interface, and component-disabled rows are rejected before setup.

Parameters
userSingle-block momentum context.
ibmMust be NULL; immersed boundaries are not supported in version one.
fsiMust be NULL; moving-body coupling is not supported in version one.
Returns
0 when the step is committed: on SNES convergence, or when SNES fails but the residual at its iterate is finite and no larger than at entry (then simCtx->mom_last_converged is false). PETSC_ERR_CONV_FAILED after rollback when that residual is non-finite or grew.
