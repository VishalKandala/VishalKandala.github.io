Updates a single particle's field based on its state and physics model.

Implements the IEM (Interaction by Exchange with the Mean) model for scalar mixing. Physics: dPsi/dt = -Omega * (Psi - Psi_mean) Solution: Psi_new = Psi_mean + (Psi_old - Psi_mean) * exp(-Omega * dt)

PetscErrorCode ComputeEulerianDiffusivity ( UserCtx *  user)

Computes the effective diffusivity scalar field (Gamma_eff) on the Eulerian grid.

This function calculates the total diffusivity used to drive the stochastic motion of particles (Scalar FDF). It combines molecular diffusion and turbulent diffusion.

Formula: Gamma_eff = nu/Sc + nu_t/Sc_t

Where:

  • nu = 1/Re (kinematic viscosity)
  • nu_t (eddy viscosity from LES/RANS model)
  • Sc (molecular Schmidt number)
  • Sc_t (turbulent Schmidt number)
Note
If turbulence models are disabled, nu_t is assumed to be 0.
This function updates the local ghost values of lDiffusivity at the end to ensure gradients can be computed correctly at subdomain boundaries.
Parameters
[in,out]userPointer to the user context containing grid data and simulation parameters.

PetscErrorCode 0 on success.

400 // Stencil: [1, -4, 3] / 2

402 }
403 else {

405 // Stencil: [-1, 0, 1] / 2
406 dGdCsi = (diff[k][j][i+1] - diff[k][j][i-1]) * 0.5;
407 }

410 // J-Direction (Eta)
411 // ---------------------------------------------------------

414 dGdEta = (-3.0 * diff[k][j][i] + 4.0 * diff[k][j+1][i] - diff[k][j+2][i]) * 0.5;
415 }
416 else if (!p_y && j == my - 2) {
417 // Physical End: Backward
418 dGdEta = (3.0 * diff[k][j][i] - 4.0 * diff[k][j-1][i] + diff[k][j-2][i]) * 0.5;
419 }
420 else {
421 // Interior: Central
422 dGdEta = (diff[k][j+1][i] - diff[k][j-1][i]) * 0.5;
423 }
424
425 // ---------------------------------------------------------
426 // K-Direction (Zet)
427 // ---------------------------------------------------------
428 if (!p_z && k == 1) {
429 // Physical Start: Forward
430 dGdZet = (-3.0 * diff[k][j][i] + 4.0 * diff[k+1][j][i] - diff[k+2][j][i]) * 0.5;
431 }
432 else if (!p_z && k == mz - 2) {
433 // Physical End: Backward
434 dGdZet = (3.0 * diff[k][j][i] - 4.0 * diff[k-1][j][i] + diff[k-2][j][i]) * 0.5;
435 }
436 else {
437 // Interior: Central
438 dGdZet = (diff[k+1][j][i] - diff[k-1][j][i]) * 0.5;
439 }
440
441 // ---------------------------------------------------------
442 // Transform to Physical Space (Cartesian Gradient)
443 // ---------------------------------------------------------
444 TransformScalarDerivativesToPhysical(aj[k][j][i],
445 csi[k][j][i], eta[k][j][i], zet[k][j][i],
446 dGdCsi, dGdEta, dGdZet,
447 &grad_diff[k][j][i]);
448 }
449 }
450 }
451
452 // 7. Restore Arrays
453 ierr = DMDAVecRestoreArrayRead(da, user->lDiffusivity, &diff); CHKERRQ(ierr);
454 ierr = DMDAVecRestoreArrayRead(fda, user->lCsi, &csi); CHKERRQ(ierr);
455 ierr = DMDAVecRestoreArrayRead(fda, user->lEta, &eta); CHKERRQ(ierr);
456 ierr = DMDAVecRestoreArrayRead(fda, user->lZet, &zet); CHKERRQ(ierr);
457 ierr = DMDAVecRestoreArrayRead(da, user->lAj, &aj); CHKERRQ(ierr);
458 ierr = DMDAVecRestoreArray(fda, user->DiffusivityGradient, &grad_diff); CHKERRQ(ierr);
459
460 // 8. Update Ghosts for the Result
461 // Important: Particles near subdomain boundaries will need to interpolate
462 // this gradient vector, so the ghosts of the vector field must be filled.
463 ierr = UpdateLocalGhosts(user, FIELD_ID_DIFFUSIVITY_GRADIENT); CHKERRQ(ierr);
464

466 PetscFunctionReturn(0);
