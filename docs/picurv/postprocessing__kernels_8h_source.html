113/**
114 * @brief Derives one accumulated statistic and converts it to nodal values.
115 *
116 * The counterpart of ComputeNodalAverage() for accumulated window state: it takes an
117 * index into a window's requested output set, normalizes the centered state behind
118 * it, and leaves the result in the shared post-processing staging field ready for
119 * output. The staging vectors are reused between calls, so a caller must consume the
120 * result before requesting the next one.
121 *
122 * Derived statistics are left non-dimensional even when `global_operations.dimensionalize`
123 * is set. A Reynolds stress scales as velocity squared and a co-moment as a product of
124 * two different scales, none of which the existing per-field scaling table expresses;
125 * silently applying a velocity scale would be wrong rather than merely incomplete.
126 *
127 * @param[in] user Block context holding the accumulators and staging fields.
128 * @param[in] window_index Window whose state is derived.
129 * @param[in] outputs Comma-separated output kinds the recipe requested.
130 * @param[in] output_index Index into that output set.
131 * @param[out] out_name Name of the derived field, window qualified.
132 * @param[in] name_size Capacity of @p out_name.
133 * @param[out] out_vec Nodal vector holding the result; borrowed, not owned.
134 * @param[out] out_components Component count of the result.
135 * @return Zero on success, or a PETSc error.
136 */
137PetscErrorCode ComputeWindowStatisticNodal(UserCtx *user, PetscInt window_index,
138 const char *outputs, PetscInt output_index,
139 char *out_name, size_t name_size,

142/**
143 * @brief Appends one convergence row for an accumulated window to its CSV history.
144 *
145 * The counterpart of ComputeParticleMSD() for Eulerian window state: it reduces the
146 * window to the few numbers that answer whether it has run long enough — sample
147 * count, total weight, represented time, the per-point valid-fraction range, and the
148 * mean turbulent kinetic energy — and appends them as one row per processed step.
149 * No single field snapshot can answer that question, which is why the history exists
150 * beside the field output rather than instead of it.
151 *
152 * The mean is taken over the fluid cells the window actually sampled. Cells outside
153 * the target domain, and cells a moving mask excluded, hold zeros that mean "never
154 * measured"; averaging over them would scale the result down by the fraction of the
155 * grid the window never covered.
156 *
157 * @param[in] user Block context holding the accumulators and staging fields.
158 * @param[in] window_index Window to summarize.
159 * @param[in] output_prefix Output path prefix; the window name and `.csv` are appended.
160 * @param[in] ti Step being processed, recorded as the row's key.
161 * @return Zero on success, or a PETSc error.
162 */
163PetscErrorCode ComputeWindowStatisticsSummary(UserCtx *user, PetscInt window_index,
164 const char *output_prefix, PetscInt ti);
