Detailed Description

The expression language shared by every configured field: a parser, a postfix compiler, and a pure stack evaluator.

Expressions are parsed into a small tree, because a chained comparison evaluates its middle operand twice, and compiled to postfix code that a stack evaluator runs once per point. A series sum(k, lo, hi, body) compiles its body once and loops over it, with the index in a slot of its nesting level. Evaluation is pure: random draws are hashed from a caller-supplied key, so a value does not depend on rank count, evaluation order, or how often it is evaluated.
