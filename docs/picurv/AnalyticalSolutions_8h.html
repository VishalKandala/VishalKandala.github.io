PetscErrorCode AnalyticalSolutionEngine ( SimCtx *  simCtx)

Sets the Eulerian fields from the case's source (-ic_source_*) at the step's time.

Sets the fluxes on every face, Ubcs on every boundary face, and Ucat and P at the cell centres. A source that does not read t is evaluated once. Collective.

Parameters
simCtxThe main simulation context, containing configuration and state.
Returns
PetscErrorCode 0 on success.

Sets the Eulerian fields from the case's source (-ic_source_*) at the step's time.

The field is the case's source, evaluated at the step's time. As on an inlet, a source that does not read t is evaluated once.

PetscBool AnalyticalFieldSupportsInterpolationError ( const SimCtx *  simCtx)

Reports whether the analytical field can be compared with interpolated particle velocities.

It must be evaluable at any point, a Cartesian source reading only x, y, z and t, and must vary in space: interpolating a uniform field has no error to measure.

Parameters
