Reduce one statistics window's velocity moments over homogeneous directions.

The covariance over the homogeneous set is the mean of the per-cell temporal covariance M2/W plus the spatial covariance of the per-cell time means: <u_a' u_b'> = mean(M2_ab / W) + mean(U_a U_b) - mean(U_a) mean(U_b).

Parameters

[in]window_nameStatistics window name from monitor.yml.
[in]grid_pathCanonical PICGRID path for the run.
[in]blockBlock index.
[in]homogeneousAxes to average over, as indices in (k, j, i) order.
Returns
Dict with numpy, nodes ((KM, JM, IM, 3) node coordinates), window (its checkpoint.meta scalars), mean (remaining axes + (3,)) and covariance (remaining axes + (6,), in M2_PAIRS order).

157 means: <u_a' u_b'> = mean(M2_ab / W) + mean(U_a U_b) - mean(U_a) mean(U_b).

159 @param[in] window_name Statistics window name from monitor.yml.
160 @param[in] grid_path Canonical PICGRID path for the run.
161 @param[in] block Block index.
162 @param[in] homogeneous Axes to average over, as indices in (k, j, i) order.
163 @return Dict with `numpy`, `nodes` ((KM, JM, IM, 3) node coordinates), `window`

Time-averaged driving acceleration a driven-periodic controller applied.

In a statistically stationary driven flow the mean force balances the mean wall stress: h = u_tau^2 for a channel of half-height h, and A = tau_w P for a duct of cross-section area A and wetted perimeter P.
