Move one periodic axis of an array of samples to another uniform resolution.

The samples are read as a truncated Fourier series, which is re-evaluated at the target points. Modes are kept only where both resolutions represent them unambiguously, |m| < min(N, M)/2, so each Nyquist mode is dropped and the result stays real.

139def _resample_axis(values, storage_axis, target_count, length, shift):
140 """!
141 @brief Move one periodic axis of an array of samples to another uniform resolution.
142 @details The samples are read as a truncated Fourier series, which is re-evaluated at
143 the target points. Modes are kept only where both resolutions represent them
144 unambiguously, |m| < min(N, M)/2, so each Nyquist mode is dropped and the
145 result stays real.
146 @param[in] values Real samples; `storage_axis` is the axis being moved.
147 @param[in] storage_axis Array axis to resample.
148 @param[in] target_count Number of target samples along that axis.
149 @param[in] length Physical period of the axis.
150 @param[in] shift Target first-sample position minus source first-sample position.
151 @return Real samples with `target_count` points along `storage_axis`.
152 """
153 numpy = require_numpy()
154 source_count = values.shape[storage_axis]
155 coeff = numpy.fft.fft(values, axis=storage_axis) / source_count
156 modes = numpy.rint(numpy.fft.fftfreq(source_count) * source_count).astype(int)
157 keep = numpy.abs(modes) < min(source_count, target_count) / 2.0
158 phase = numpy.exp(1j * 2.0 * numpy.pi * modes[keep] * shift / length)
159 shape = [1] * values.ndim
160 shape[storage_axis] = int(keep.sum())
161 kept = numpy.compress(keep, coeff, axis=storage_axis) * phase.reshape(shape)
162 out_shape = list(values.shape)
163 out_shape[storage_axis] = target_count
164 target = numpy.zeros(out_shape, dtype=complex)
165 index = [slice(None)] * values.ndim
166 index[storage_axis] = modes[keep] % target_count
167 target[tuple(index)] = kept
168 return (numpy.fft.ifft(target, axis=storage_axis) * target_count).real

Resample a triply periodic vector field onto another uniform grid, optionally filtered.

Exact for band-limited data: every mode both grids resolve is carried over with its amplitude and phase, then the filter multiplies its transfer function. Each axis is moved separately, so memory stays at one array of the larger size.
