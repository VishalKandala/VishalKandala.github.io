1/**
2 * @file statistics_target.h
3 * @brief Spatial target resolution for the field-statistics pipeline.
4 *
5 * Implements the pointwise identity mapping described in @ref p58_target_sec. The
6 * abstraction exists with only that one mapping so later spatial bins, profiles,
7 * regions, and surfaces extend it rather than retrofit it; see
8 * @ref 60_Field_Statistics_Planned_Extensions.
9 *
10 * The central responsibility is producing an iteration domain that excludes two
11 * distinct categories which @ref 56_Field_Identity_and_Layout_Catalog section 4
12 * warns must not be conflated:
13 *
14 * 1. PETSc/MPI halo entries created by DMDA decomposition, and
15 * 2. solver-layout boundary, dummy, or duplicate-periodic indices, which exist
16 * even on a single MPI rank.
17 *
18 * Nothing here resolves field identity or layout metadata itself; that comes
19 * from the typed catalog through `FieldGetDescriptor`.
20 */

41/**
42 * @brief Resolved iteration domain for one field on one block.
43 *
44 * Bounds are half-open `[start, end)` in DMDA index order `(i, j, k)` and are
45 * already intersected with this rank's owned range, so iterating them touches
46 * neither halo storage nor layout boundary/dummy/duplicate-periodic indices.
47 * An empty domain on a rank is represented by `end[d] <= start[d]`.
48 */
49typedef struct {
50 PicurvTargetKind kind; /**< Spatial mapping; always pointwise. */
51 PicurvStatisticsMask mask; /**< Point-eligibility mask. */
52 const FieldDescriptor *descriptor; /**< Catalog metadata for the targeted field. */
53 PetscInt start[3]; /**< Inclusive start per dimension (i, j, k). */
54 PetscInt end[3]; /**< Exclusive end per dimension (i, j, k). */
55} SpatialTargetPlan;

129/**
130 * @brief Averages two fields over a target domain and divides the results.
131 *
132 * Computes `ratio = <numerator> / <denominator>`, where each average is taken
133 * separately over the points the plan admits, and then divides. The order matters:
134 * the mean of the pointwise quotients is a different number from the quotient of the
135 * means, and several callers need the second one. The LES dynamic procedure is one,
136 * because Lilly's least-squares closure is defined that way.
137 *
138 * `average_direction` selects which logical directions collapse into the average.
139 * Selecting none makes the operation pointwise, which lets a caller express a local
140 * and an averaged formulation through one code path rather than two. Selecting all
141 * three yields one number for the whole domain. Selecting a subset retains a profile
142 * along the directions left out — averaging over xi and zeta on a plane channel, for
143 * example, leaves a wall-normal profile.
144 *
145 * Weighting is the caller's, not this function's: scale @p numerator and
146 * @p denominator by whatever weight the average should carry before calling. A
147 * caller wanting a volume-weighted average multiplies both by the cell volume; a
148 * caller wanting each admitted point to count once passes them unscaled.
149 *
150 * The reduction runs over @p comm, so a result is independent of how the domain is
151 * decomposed across ranks. The plan already excludes PETSc halo storage and the
152 * solver's boundary, dummy, and duplicate-periodic indices, so no physical point is
153 * counted twice.
154 *
155 * @param[in] user Block context supplying the DMDA and the solid mask.
156 * @param[in] plan Resolved iteration domain, from `SpatialTargetPlanCreate()`.
157 * @param[in] numerator Ghosted local field to average in the numerator.
158 * @param[in] denominator Ghosted local field to average in the denominator, or NULL
159 * to divide by the number of admitted points.
160 * @param[in] inclusion Optional second mask: points where this field is not
161 * positive are skipped. Use it to exclude points that hold a
162 * zero meaning "never measured" rather than a measurement.
163 * NULL applies the plan's mask alone.
164 * @param[in] average_direction Directions to average over, in `(xi, eta, zeta)` order.
165 * @param[in] comm Communicator to reduce over.
166 * @param[out] ratio Ghosted local field receiving the quotient, or NULL when only
167 * the scalar is wanted. Zero wherever the averaged denominator
168 * underflows.
169 * @param[out] scalar Receives the single averaged value, or NULL. Valid only when
170 * every direction is averaged, since otherwise there is no
171 * single value to report.
172 * @return Zero on success, `PETSC_ERR_ARG_OUTOFRANGE` when the retained directions
173 * would need an unreasonably large reduction buffer, or
174 * `PETSC_ERR_ARG_WRONGSTATE` when a scalar is requested from a result that
175 * still varies in space.
176 */
177PetscErrorCode PicurvSpatialRatioAverage(UserCtx *user, const SpatialTargetPlan *plan,
178 Vec numerator, Vec denominator, Vec inclusion,
179 const PetscBool average_direction[3], MPI_Comm comm,
180 Vec ratio, PetscReal *scalar);
