Detailed Description

Fourier machinery for the uniform periodic axes of PICurv's Cartesian grids.

Shared by ic.gen, which synthesizes and resamples initial conditions, and spectra.gen, which measures spectra; both load it from picurv_cli/. Both need the same answer to three questions: which axes may be transformed, what the continuum and PICurv-discrete wavenumbers are, and how a periodic field is moved between resolutions. Arrays are in PICurv storage order, [k, j, i, component]; lengths and wavenumbers are in Cartesian x, y, z order. Every function imports NumPy through require_numpy(), so importing this module never imports NumPy itself.
