Detailed Description

The canonical PICGRID text grid format: its coordinate precision, header reader and coordinate reader, shared by the conductor and the generators.

Not a command. core.py, grid.gen, ic.gen, profile.gen, reduce.gen and spectra.gen import it from picurv_cli/, as they import petsc_binary.py. A PICGRID file is the token PICGRID, a block count, one IM JM KM node-count row per block, then every block's node coordinates in block order, one x y z row per node with i fastest, then j, then k. Blank lines and lines beginning with # are not part of the content.
