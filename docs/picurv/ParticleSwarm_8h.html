Detailed Description

Header file for Particle Swarm management functions.

This file contains declarations of functions responsible for creating, managing, initializing, migrating, and printing particle swarms within a simulation using PETSc's DMSwarm.

Creates the particle swarm, registers its fields and sizes it for this rank's share.

Volume and Surface seeding give each rank the particles its owned cells seed (by volume, or by area on the inlet face, the stratified split of the seeding table); PointSource divides the count evenly, the first ranks taking one more. Collective.

Parameters
[in,out]userFinest-level context; receives the swarm.
[in]numParticlesTotal number of particles to create across all MPI processes.
[out]particlesPerProcessNumber of particles assigned to the local rank.
Returns
PetscErrorCode Returns 0 on success, non-zero on failure.

Creates the particle swarm, registers its fields and sizes it for this rank's share.

Initializes all particle properties in the swarm.

Surface seeding requires an INLET face. The basic properties (physical position, particle ID and the seeded cell) are set by InitializeParticleBasicProperties: Volume and Surface seeding stratify the particles over the cells' volume or inlet area and key every placement draw on (seed, particle ID), so the population does not depend on the rank layout. Every field the particle catalog marks for default initialization (velocity, weight, Diffusivity, DiffusivityGradient and Psi) then takes its catalog default. Collective.

[in]particlesPerProcessNumber of particles assigned to this MPI process.

PetscErrorCode Returns 0 on success, non-zero on failure.

PetscErrorCode InjectParticlesAtInlets ( UserCtx *  user)

Add the particles that entered through each injecting inlet during this step.

Collective. A face cell receives on average n (u.A) dt particles, none where the flow leaves, so the entering fluid has number density n whatever its velocity profile. Counts, positions and identities come from keyed draws on the grid position, the step and the particle, so they carry no state and do not depend on the rank layout. A particle is placed just inside the face, by area and inward velocity, and its field values are set there, where it crossed. It then moves in by a uniform share of dt times the velocity the configured interpolation method gives at that point (the face cell's mean inward velocity where the cell has none) plus this step's Brownian kick from the face cell's diffusivity.
