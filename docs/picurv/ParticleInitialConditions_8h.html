Detailed Description

Configured initial values of particle-carried fields.

A plan binds each configured particle field to one compiled expression per component. Expressions are written in physical units: x, y, z are physical coordinates, t is physical time, and a value is divided by its field's catalog reference scale when written. The plan is applied to a contiguous local range of swarm entries, so the t=0 population and, later, particles injected at a boundary share one path.

The expressions are compiled and evaluated by the shared engine in expression.h.

Write the plan's values into swarm entries [first, end) of this rank.

Each rank evaluates its own entries. Every rank calls it even with an empty range: the first call that reads a grid line's fraction or length is collective, computing them once for the plan. Zero on success.
