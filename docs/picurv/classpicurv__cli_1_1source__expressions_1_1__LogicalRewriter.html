Detailed Description

Rewrite logical operators and chained comparisons into array operations.

and, or, not and a chain a < b < c have no elementwise meaning for arrays, so they become logical_and, logical_or, logical_not calls, the same 1-or-0 semantics the runtime evaluator gives them.
