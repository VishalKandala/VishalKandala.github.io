Detailed Description

The expression language shared by every configured field, and the keyed hashes its random draws and other reproducible draws are built from.

Callers compile an expression against their own list of variable names and supply the values in that order at evaluation. generators/ic.gen validates the same language; tests/fixtures/expression_conformance.txt holds cases both implementations must agree on.

Compile one expression against a list of variable names.

The grammar is Python's expression syntax restricted to numbers, the given names, pi, arithmetic (+ - * / % **), comparisons (chained ones included), and/or/not, and the functions abs atan2 cos cosh erf exp floor log maximum minimum sin sinh sqrt tan tanh where, plus uniform and normal when allow_random is true. Comparisons and logical operators yield 1 or 0; % takes the sign of the divisor; ** binds tighter than a unary minus on its left and groups to the right.

Parameters

[in]namesVariable names, in the order evaluation supplies their values.
[in]name_countNumber of names.
[in]allow_randomWhether uniform and normal may be called.
[out]expressionCompiled expression, owned by the caller.
Returns
Zero on success; PETSC_ERR_ARG_WRONG for a syntax error or an unknown name or function, with the offending position in the message.

Add a source's flux to every owned face of Ucont, evaluating it at each face centre.

A Cartesian velocity is dotted with the face metric; a curvilinear component is the speed through the face, times its area; a contravariant component is the flux itself.

Parameters
[in,out]userBlock whose Ucont receives the fluxes.
[in]sourceSource with expressions.
[in]fractionGrid-line fractions, from ComputeGridLineFractions().
[in]lengthGrid-line lengths, from ComputeGridLineFractions().
[in]physical_timeTime [s].
[in]factorFactor on the expressions.
[in]boundary_facesWhether the boundary - faces are set too; each cell's + face always is.
Returns
PETSc error code.
