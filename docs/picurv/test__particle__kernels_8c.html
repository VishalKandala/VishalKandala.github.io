static PetscErrorCode TestExpressionDrawsArePureAndKeyed ( void  )
static

Tests that random draws are pure functions of their key.

The same particle always draws the same number; a different particle, event, or field default stream draws independently; an explicit stream is shared across fields; and the normal draw has zero mean and unit variance.
