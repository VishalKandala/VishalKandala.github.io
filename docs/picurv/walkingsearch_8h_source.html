151/**
152 * @brief Finds the MPI rank that owns a given global cell index.
153 * @ingroup DomainInfo
154 *
155 * The DMDA decomposition is a tensor product of per-axis ranges, with rank
156 * i + m (j + n k) on process grid m x n x p, so the owner is found by a binary search of
157 * the range starts along each axis in the pre-computed decomposition map
158 * (`user->RankCellInfoMap`): O(log m + log n + log p), not O(ranks). It is the definitive
159 * method for resolving cell ownership in the "Walk and Handoff" migration algorithm.
160 *
161 * If the provided indices are outside the range of any rank (e.g., negative or
162 * beyond the global domain), the function will not find an owner and `owner_rank`
163 * will be set to -1.
164 *
165 * @param[in] user Pointer to the UserCtx structure, which must contain the
166 * initialized `RankCellInfoMap` and `num_ranks`.
167 * @param[in] i Global i-index of the cell to find.
168 * @param[in] j Global j-index of the cell to find.
169 * @param[in] k Global k-index of the cell to find.
170 * @param[out] owner_rank Pointer to a `PetscMPIInt` where the resulting owner rank will
171 * be stored. It is set to -1 if no owner is found.
172 *
173 * @return PetscErrorCode 0 on success, or a non-zero PETSc error code on failure.
174 */
175PetscErrorCode FindOwnerOfCell(UserCtx *user, PetscInt i, PetscInt j, PetscInt k, PetscMPIInt *owner_rank);

191/**
192 * @brief Moves a point to just inside a cell along the segment toward the cell centroid.
193 *
194 * The terminal action when reflections reach their cap. Plane distances are linear along the
195 * segment, so the entry parameter is the largest d_p / (d_p - d_c) over the faces the point is
196 * outside of; the point is placed a relative 1e-6 of the remaining segment beyond it.
197 *
198 * @param[in] cell The cell to place the point in.
199 * @param[in,out] p The point; unchanged when it cannot be placed.
200 * @param[out] placed PETSC_FALSE when the centroid is not inside every face plane the point
201 * is outside of (a cell warped that far), in which case `p` is unchanged.
202 *
203 * @return PetscErrorCode 0 on success, or a non-zero PETSc error code on failure.
204 */
205PetscErrorCode PlaceParticleInsideCell(const Cell *cell, Cmpnts *p, PetscBool *placed);

207/**
208 * @brief Locates a particle's host cell or identifies its migration target using a robust walk search.
209 * @ingroup ParticleLocation
210 *
211 * This is the core search engine. It starts from a guess cell and walks through
212 * the grid. It returns a definitive, actionable status indicating the outcome:
213 * - `ACTIVE_AND_LOCATED`: The particle was found in a cell on the current rank.
214 * - `MIGRATING_OUT`: The particle was found to belong to another rank. `particle->destination_rank` is set.
215 * - `EXITED`: The particle lies beyond a domain-boundary face of the boundary cell the walk reached,
216 * with every face it is outside of on the domain boundary and at least one of them using the
217 * `remove` particle policy. When all of them use `reflect`, the particle is instead mirrored
218 * about the most-crossed face (`ReflectParticleAcrossCellFace`) and the search continues; after
219 * `REFLECTION_CAP` reflections it is placed just inside the cell (`PlaceParticleInsideCell`).
220 * - `NEEDS_LOCATION` (with `cell` reset to -1): a pass-1 walk from the previous-step cell ended more
221 * than `BLOCKED_WALK_GUARD_CELLS` cell sizes beyond the boundary, so the walk was most likely blocked
222 * by a non-convex boundary; the caller searches the particle again from scratch.
223 * - `LOST`: The search failed for a particle believed to be inside the domain.
224 *
225 * This function is globally aware and can walk across MPI rank boundaries. It contains
226 * robust checks for global domain boundaries and a tie-breaker for numerically "stuck"
227 * particles on cell faces. A face lies on the domain boundary when the cell index is at the
228 * extreme of that axis, the same test the boundary-condition handlers use.
229 *
230 * @param[in] user Pointer to the UserCtx containing all grid and domain info.
231 * @param[in] planes The block's primal face-plane arrays, already open with
232 * `MetricGetFacePlaneArrays()`, or NULL to open and close them here.
233 * A caller searching many particles opens them once and passes them.
234 * @param[in,out] particle Pointer to the Particle struct. Its fields are updated based
235 * on the search outcome.
236 * @param[out] status_out The final, actionable status of the particle after the search.
237 *
238 * @return PetscErrorCode 0 on success, or a non-zero PETSc error code on failure.
239 *
240 * @note Testing status:
241 * This function is exercised indirectly by the orchestrator tests, but
242 * direct branch pinning for boundary clamp, ghost-region handoff,
243 * tie-breaker, `LOST`, and `MIGRATING_OUT` outcomes is still part of the
244 * next-gap test backlog.
245 */
