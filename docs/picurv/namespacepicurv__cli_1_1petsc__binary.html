Read a real64 PETSc binary VecView payload.

The header's class id and count are PetscInt of index_bytes, the width of the PETSc that wrote the file, which the file does not record. Either byte order is accepted, with or without the class id; the file length must match exactly.

28 """!
29 @brief Read a real64 PETSc binary VecView payload.
30 @details The header's class id and count are PetscInt of `index_bytes`, the width of the
31 PETSc that wrote the file, which the file does not record. Either byte order is
32 accepted, with or without the class id; the file length must match exactly.
33 @param[in] path PETSc binary vector path.
34 @param[in] numpy The caller's numpy module.
35 @param[in] index_bytes Bytes of a PetscInt in the writing PETSc, 4 or 8.
36 @param[in] label How the caller names the file in errors.
37 @return NumPy array of scalar values.
38 """
39 if not os.path.isfile(path):
40 raise ValueError(f"{label} not found: {path}")
41 with open(path, "rb") as fin:
42 data = fin.read()
43 word, code = index_bytes, _index_code(index_bytes)
44 if len(data) < 2 * word:
45 raise ValueError(f"{label} '{path}' is too short to be a PETSc Vec binary.")
46 candidates = []
47 for endian in (">", "<"):
48 (vec_size,) = struct.unpack_from(endian + code, data, word)
49 if vec_size > 0 and len(data) == 2 * word + vec_size * 8:
50 candidates.append((endian, vec_size, 2 * word))
51 (vec_size_no_class,) = struct.unpack_from(endian + code, data, 0)
52 if vec_size_no_class > 0 and len(data) == word + vec_size_no_class * 8:
53 candidates.append((endian, vec_size_no_class, word))
54 if not candidates:
55 raise ValueError(
56 f"{label} '{path}' does not match a PETSc real64 Vec binary with "
57 f"{index_bytes}-byte indices; a file from the other index width does not fit."
58 )
59 endian, vec_size, offset = candidates[0]
60 values = numpy.frombuffer(data, dtype=numpy.dtype(endian + "f8"), count=vec_size, offset=offset)
61 return values.astype(float, copy=False)

79 """!
80 @brief Validate the envelope the solver's ReadFieldData loads: big-endian, with the class id.
81 @details Stricter than read_petsc_vec_binary(), which also takes either byte order, with or
82 without the class id: this guards a file the solver itself will read.
83 @param[in] path PETSc binary vector path.
84 @param[in] index_bytes PetscInt width of the reading build.
85 @return Summary containing the absolute path, scalar count and index width.
86 """
87 header_bytes = 2 * index_bytes
