static PetscErrorCode TestDummyCellsFollowEachFieldsBoundaryRule ( void  )
static

Checks each cell-centred field's dummy-cell rule, faces then edges.

Interior cells carry index-unique sentinels and every dummy cell starts poisoned, so a wrong offset or a missed face shows. Velocity dummies must put the face average on Ubcs; pressure and the particle scalar copy the adjacent cell (zero normal gradient); each edge dummy is the mean of its two face neighbours; and a field with no rule, or one that is not cell-centred, is refused.
