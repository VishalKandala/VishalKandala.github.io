static PetscErrorCode TestFieldStatisticsPointVarianceProfile ( void  )
static

A point_variance profile is the plane mean of each point's own variance.

Two states differ at each point by i + 1, so every point's variance is ((i + 1)/2)^2 while the point means also vary across the plane. The profile must carry the equal-weight mean of the point variances, without the spread of the point means that the pooled RMS includes, on any decomposition.
