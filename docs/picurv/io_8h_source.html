544 * consistent periodicity for each dimension, reusing the core type parser.
545 *
546 * This is a lightweight pre-parser intended to be called before DMDA creation.
547 * It ensures that the periodicity setting is consistent across all blocks, which is a
548 * physical requirement for the domain.
549 *
550 * 1. It collectively verifies that the mandatory BCS file for each block exists.
551 * 2. On MPI rank 0, it then iterates through the files.

558 * specify the same global periodicity.
559 * 7. It broadcasts the final three flags (as integers 0 or 1) to all MPI ranks.
560 * 8. All ranks update the i_periodic, j_periodic, and k_periodic fields in their SimCtx.
561 *
562 * @param[in,out] simCtx The master SimCtx struct, containing the bcs_files list and
