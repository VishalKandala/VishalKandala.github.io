◆ TestComputeCellCharacteristicLengthScaleWallResolvedCell()

static PetscErrorCode TestComputeCellCharacteristicLengthScaleWallResolvedCell ( void  )
static

Tests the length scales of a wall-resolved cell, whose metrics are tiny.

The determinant of the face-area vectors is the square of the cell volume for an orthogonal cell, so it falls as the sixth power of the spacing. The cell here is one from the Humphrey wall-resolved grid: 4.73e-4 x 4.73e-4 x 3.05e-2, whose determinant is about 4.7e-17. An absolute singularity floor rejected it and left the length scales uninitialized, which reached the solver as a NaN eddy viscosity rather than as an error.
