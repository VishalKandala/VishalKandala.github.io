static PetscErrorCode ApplyFaceBoundaryVelocity ( BoundaryCondition *  self,
BCContext *  ctx,
FaceBoundaryVelocityRule  rule 
)
static

Sets a handler's boundary velocity and the face flux it implies on one face.

Shared by every handler that prescribes a Cartesian velocity at its face: the inlets, the no-slip wall and the free-slip wall. For each boundary slot this rank owns it asks rule for the velocity, stores it as the boundary value, and sets the face flux to its product with the face metric. A rule whose velocity is tangent to the face therefore closes the face. A slot whose fluid side is blanked (nvert > 0.1) belongs to an immersed body, whose own boundary condition applies there, so it is left untouched.

Parameters
selfHandler being applied.
ctxBoundary context naming the face.
ruleVelocity the handler prescribes, given the slot, the face metric, the side (sign, positive on a negative face) and the adjacent interior velocity.
Returns
PetscErrorCode 0 on success.
